## Limites
Le format 1920×1080 exact n'a pas été qualifié sur un écran configuré ainsi ; la vue initiale redimensionnable a été observée. Restauration par menu tray, déconnexion physique réseau, fin réelle de session média et changements multi-applications restent à qualifier ; calculs/effacement couverts par tests injectés.
Sélection réseau heuristique (passerelle IPv4), pas une analyse des tables de routage ; VPN et machines multi-interface peuvent nécessiter une sélection explicite ultérieure.
SMTC dépend des métadonnées exposées par chaque application. GPU limité à NVIDIA 0. Package dépendant du runtime local, sans installateur autonome. Une seule instance à lancer.
