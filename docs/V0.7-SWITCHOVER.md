# AXIS V0.7 — Bascule réversible du collecteur

Les données CONTROL sont importées dans le profil AXIS indépendant. CONTROL reste sur 127.0.0.1:4177 ; AXIS reste sur 127.0.0.1:4187. Aucun arrêt ni changement Chrome automatique.

1. Lancer Launch-AXIS.cmd et ouvrir PROJECTS. Vérifier les projets, statuts, sources et reprises. Import/options permet de refaire une prévisualisation : créations, mises à jour et conflits sont indiqués ; les valeurs AXIS gagnent en cas de conflit. Les suppressions locales et affectations manuelles restent prioritaires.
2. Dans Import/options, vérifier « récepteur prêt ». Renseigner l’identifiant de l’extension Chrome installée (32 lettres a-p), puis autoriser cette identité. Ce bouton redémarre uniquement le récepteur interne AXIS. Il ne modifie pas l’extension. Si un Bearer est configuré dans CONTROL/collecteur, lancer AXIS avec la même variable SHINO_CONTROL_TOKEN ; aucun secret n’est copié dans les rapports ou l’interface.
3. Après accord sur la collecte privée, cocher son autorisation dans AXIS. La synchronisation GitHub automatique est un consentement distinct.
4. Après autorisation de bascule Chrome, noter l’ancien endpoint du collecteur puis remplacer uniquement sa valeur endpoint dans chrome.storage.local par http://127.0.0.1:4187/api/ingest/chatgpt-delta, via les options ou la console du service worker de l’extension. Conserver ses autres paramètres et son token existant. Ne pas installer une seconde extension ni ajouter un deuxième destinataire.
5. Valider une observation contrôlée et un rattrapage ciblé. PROJECTS doit indiquer un nouveau « dernier delta reçu par AXIS » ; vérifier le projet, son état, sa prochaine action et ses sources. Les données « Historique source (CONTROL inclus) » importées ne sont pas une preuve de réception AXIS. Refaire la même observation : pas de duplication ni de réécriture du stockage pour un fingerprint inchangé.
6. Vérifier le report de rattrapage : nouvelles/modifiées, rafraîchies, différées, échecs. Un timeout est refroidi 30 min, 2 h, 6 h puis 24 h ; une nouvelle date distante peut lever ce refroidissement. Une conversation inaccessible ne doit pas devenir un succès inventé.
7. Ne retirer CONTROL du démarrage qu’après validation de cette chaîne et accord distinct. Cette mission ne le fait pas.

Retour : rétablir le seul endpoint précédent (normalement http://127.0.0.1:4177/api/ingest/chatgpt-delta) dans le même collecteur, puis désactiver la réception privée AXIS. Ne pas supprimer les données AXIS ou CONTROL. Les observations postérieures à la bascule ne sont pas recopiées automatiquement vers CONTROL : un retour de destinataire ne constitue pas une fusion inverse.

Contrats AXIS : POST /api/ingest/chatgpt-delta, POST /api/chatgpt/catchup-plan et POST /api/chatgpt/catchup-report. Ils utilisent le Host loopback exact, une origine autorisée, un JSON borné, le même Bearer éventuel et le consentement local. GET /api/health permet un contrôle local de disponibilité. Aucun accès LAN.

L’essai réel de l’extension Chrome reste à faire après autorisation. Les API internes ChatGPT utilisées par l’extension restent non documentées et susceptibles de changer.
